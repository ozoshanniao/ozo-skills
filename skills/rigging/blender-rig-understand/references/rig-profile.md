# 角色语义档案

按角色保存实际数据，未知项明确为 unknown；不要求为了填表猜测。

## 身份与环境

记录文件/场景/实例、Blender 版本、骨架对象与数据块、网格绑定、单位/FPS、对象变换，以及本地/链接/Override 的可写状态。记录 Action 和实际 Slot，不能默认第一个 Slot。记录 NLA、约束/驱动和形态键是否贡献运动。

## 控制器记录

每个角色职责可对应多个控制器。推荐字段：
- semantic_role：例如 body、pelvis、left_hand、right_foot，不依赖具体骨名。
- controller：对象/骨名及属性路径；左右侧与末端定义。
- result：用于验证的求值骨、网格区域/接触点。
- parent_and_space：真实父链、约束目标/顺序和拥有者/目标空间。
- channels：平移/旋转/缩放、旋转模式、锁定轴、允许伸缩。
- mode：IK/FK、跟随、父空间属性的实际值与含义、动画范围。
- evidence：驱动/约束依据、求值样本；读取得到还是通过操作验证。
- snap_method：保姿吸附接口、调用上下文与限制；未测则不当成可靠能力。
- limits：可读但不可写、约束覆盖、活动模式无效通道等。

## 比例与适配

保存角色高度、肩宽和相关肢长，注明静止姿态或测量帧。动作幅度按身体参照系及比例适配，目标接触点使用目标局部空间。地面法向和角色朝向需确定，不将世界 Z 或角色本地某轴无条件当作通用约定。

## 验证状态

区分“名称存在”“结构追踪确认”“副本操作验证”“最终网格检查”。真实角色参数进入档案，不进入通用 Skill 指令。新增角色结构变化后重验受影响部分。
