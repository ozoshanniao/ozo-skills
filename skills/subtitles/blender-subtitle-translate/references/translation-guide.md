# 翻译约定

## 教学语言与条目对齐

按讲师实际操作和教学意图翻译，不逐词拼接。可精简无信息的口头填充词，但保留尝试、撤销、纠正、条件和因果；先说错再改口时，不把最终步骤伪装成从未发生纠正。

相邻字幕可能组成一句话；先理解整句，再让各条中文随对应英语语音推进。跨条调整语序限于自然表达所需的小范围，不大幅提前透露操作，不把任何一条清空。

纯中文版本允许必要英文界面名和代码；双语版另附完整英文。避免在每个条目中给所有普通名词加英文。

## 术语决策

优先级：用户或课程指定词表 → 同课程已确认译法 → 与课程版本相符的 Blender 官方中文术语 → 行业内明确、自然且一致的译法。与版本相关或不确定的具体名称，查该版本官方手册或官方翻译资源；不凭印象声称某词就是“官方译名”。仅在实际需要核实时检索，不为普通字幕翻译强制联网。

关键术语通常写作 `中文（English）`，在本课首次出现、新教学段落或易混位置标注；后续可用中文简称。用户强调每次对照时可提高标注频率。

同一英语词在对象、模式、骨骼、节点或普通句子中含义可能不同。先判断它是界面名称、概念还是口语动词，不能机械替换。例如 parent 不能一律译成“父母”，apply 也不在所有语境中代表同一种操作。

界面英文名称与大小写尽量跟随源文件。源转录拆错名称时，译文可使用经语境确认的正确名称，双语版英文仍不改。无画面或参考资料支持的猜测列为待确认项。

## 操作信息

- 精确保留快捷键、顺序与鼠标操作；区分同时按键和先后操作、数字行与小键盘。源文中的 Numpad 不能简化为普通数字键。
- 保留 X/Y/Z、正负方向、局部/全局空间、左右前后、选择顺序、活动对象及吸附对象的区别。
- 保留数值、负号、小数、单位、帧数、起止范围与连接关系；不自行换算或取整。
- 代码、Python API 标识符、路径、变量、插件名和自定义对象名保持原样。自然语言说明可翻译，代码字符串和标识符不汉化。
- 区别节点名与端口，明确输入、输出及连接方向。不要混淆对象变换、网格编辑和应用变换。
- 保留样式标签及作用范围，如 `<i>...</i>`；保留 `\N` 等控制标记的语义。

## 复核

逐条查未译的英语讲解整句，不能仅凭“出现拉丁字母”判断漏译。检查否定、修正、单位和条件。同课程的同义术语保持一致，同形异义词按语境区分。

按语义换行，避免拆开快捷键、数字与单位、中文术语与括号英文。以读得完为目标，不设适用于所有播放器的固定字数硬限制。读速过高时压缩冗词并记录难以解决的条目，保持时间轴不变。
