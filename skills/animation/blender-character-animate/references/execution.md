# MCP 执行与动画数据

## 跨环境接口

发现当前工具而非假定特定 MCP 名称。确认支持读取场景、执行 Blender Python、获取图像中的哪些功能。遵守实际工具参数要求；工具不支持多实例选择时，不用默认连接替代用户选择。传入代码需符合当前 Blender 版本，必要时检查 RNA/实际插件实现，不凭记忆硬编码枚举和操作符。

SKILL.md 为通用 Markdown 工作流；不同代理仍需支持技能加载与对应 MCP。没有实际测试不能宣称已兼容 Antigravity 或其他产品。不要为适配技能擅自修改其他代理配置。

## 最新基线

写入前记录：
- 文件/场景、目标对象/数据、单位/比例、世界变换、模式/选择、帧和子帧；
- Action、实际 Slot、使用者、保留状态、真实曲线范围，另记时间轴播放范围；
- NLA 的 use_nla、mute、strip 时间映射、混合/影响值及约束/驱动；
- 相关控制器通道、旋转模式、自定义属性、IK/FK、空间跟随；
- 用户最新手调及对本次修改的范围要求。

只读检查只记录/采样，临时状态在 finally 中恢复。新 Action 的制作不能无条件恢复成旧绑定从而让交付不可播放；恢复环境状态与交付状态须区分。

## Action 与曲线

按运行版本选择传统 FCurve 或 layered Action 的 layer/strip/channelbag 接口，只处理实际兼容 Slot。复制/绑定后验证曲线确实驱动目标；多槽混合对象不可默认 slots[0]。

新动作是独立 Action 数据块。保留原版，复制测试的数据和约束/驱动引用须正确隔离，不能仅复制对象却仍通过共享数据修改原角色。必要时为不活动 Action 设置保留方式，不把共享 Action 修改为角色独占副本却不检查其他用户。

保留用户有意烘焙的 FK 与 IK 曲线。只为当前实际生效的入口写入所需通道；是否同步另一套控制器取决于用户编辑目的及已验证的吸附流程，不自动重烘焙全部模式。

用原生旋转模式，保持四元数符号连续、避免欧拉角绕圈；跨坐标空间使用静止基和父级关系转换，不直接搬角度。关键帧插值按通道职责选择，离散开关不以平滑过渡替代保姿切换。

## 求值与预览

每次切帧后取依赖图求值的骨/网格；读取原始控制器与结果骨是两类证据。临时网格用完释放。预览采用实际角色/目标物，避免控制形状或隐藏源骨架误导；必要时临时改变显示并恢复。

先关键姿态和接触锚点，再完善过渡。需要高密烘焙时选择覆盖动作的采样密度，并检查子帧插值；不把“每帧烘焙成功”当成最终验证。

## 失败与提交

分离候选结果与正式绑定，检查通过后核对实时基线再提交。失败恢复原绑定、Slot 和相关模式/属性；切回原 Action 不一定恢复未打键开关，须实际复验。

避免无限正式重烘焙。有限次小范围试验没有改善时诊断原因，保留可用版本；依赖用户未答复的运动分配时停止相关写入。未经指示不保存 .blend、不导出、不安装插件或下载付费资源。
