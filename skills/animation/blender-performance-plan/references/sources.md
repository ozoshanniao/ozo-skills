# 参考资料与使用边界

2026-11-04 检索并阅读文章正文；没有逐帧观看其内嵌视频。下列方法需在当前绑定上实现并验证。

- [Animation Mentor：Character Turnaround](https://www.animationmentor.com/blog/animate-a-character-turnaround/)：转身中的换重心、迈步、肩髋扭转、关键姿态、过渡及多角度检查。Maya 操作、特定骨架和案例帧数不照搬。
- [Animation Mentor：Emotion Through Body Language](https://www.animationmentor.com/blog/tutorial-animating-emotion-through-body-language/)：用肩背、手脚、轮廓、姿态及节奏塑造情绪。作品案例不是全人群固定的身体语言规律。
- [Walt Disney Animation Studios：Animation](https://disneyanimation.com/process/animation/)：节奏、预备、跟随、次要动作与重量/解剖知识共同服务角色表演。该页介绍原则，不提供执行参数。
- [AnimSchool：Animating Weight](https://blog.animschool.edu/2025/05/02/animating-weight/)：参考支撑、用力与响应的关系；不采用该文“重物下落更快”的概括作为物理规则。
