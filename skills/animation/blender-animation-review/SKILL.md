# 检查与润色角色动画

区分检查与修改。用户说分析/检查时只读，报告发现；用户要求修复或润色时才修改相应范围。默认自然可信，尊重刻意风格化和最新手调。没有明确循环需求不把所有端点差都当作错误。

## 获取可比较的基线

核对实时 MCP 实例/文件、场景、角色、Action/实际 Slot、完整曲线范围、FPS、单位、NLA、IK/FK、空间和根运动要求。多个实例未选定时先选定；无实时连接不得以旧文件代替。临时切帧/显示状态在 finally 中恢复，不保存 .blend。

确认实际控制权和所有运动来源。用户有意烘焙的 FK/IK 曲线不是待清理冗余；判断结果以依赖图求值为准。用户要求涉及身体位移或旋转的修订时，必须先询问各自写入的位置/轴/根运动方案并等待答复；当前曲线分布不是答复，明确覆盖本次范围的已有答复可沿用。只读诊断可继续。

## 检查动作

按用途和风险读 [验收方法](references/review-criteria.md)，检查完整相关范围和必要子帧：
- 主体与四肢轨迹、根运动、方向、姿态/速度跳变及异常伸缩；
- 膝肘弯曲平面、Pole、IK/FK/空间切换、手指和实际网格变形；
- 支撑、脚跟脚尖滚动、手/道具/座面接触、释放与穿插；
- 循环和连接处的姿态、速度、必要角速度及接触连续；
- 相机/游戏观察角度下的动作可读性、节奏、注意对象和主次关系。

使用实际鞋底、臀部、掌面与目标表面；无实际地面或道具时区分假定平面/代理检查，不能宣布最终接触通过。骨盆位置不是物理重心；未做物理计算不宣称平衡已验证。

## 报告与修订

每个实质发现提供部位、帧段/最差帧、证据、单位与可见影响，区分原因确认、推测和有意动作。阈值根据角色比例和用途判断，不把历史厘米/角度设成全局标准。视觉观察与数值测试相互支持；未检查的内容不标通过。

需要修改时在独立 Action 副本上处理已授权范围，优先定位来源/模式/空间和接触计划等上游原因，再修局部曲线。用户允许按需使用辅助物体、代理道具、临时约束和烘焙，不需要重复询问这项许可；不能因此改绑定结构或跳过位移/旋转答复。

修订后复查受影响范围、邻近子帧及衔接，验证未授权部分和原动作保持。反复试验无改善时停止正式提交，保留基线并诊断；用户并行手调后重新合并最新状态，不能用旧副本覆盖。

交付原/新 Action、实际 Slot、范围与检查方法、根运动方案、辅助依赖、残余问题和是否写盘。让用户能直接播放候选结果，再讨论表演修改。没有图像/播放观察时明确视觉检查限制，不把结构检查当成自然度验收。
