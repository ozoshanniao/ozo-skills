# 男角色 → 女角色动画转换

将已校准的两套绑定转换为女角色专用 Action。通过源与目标静止基换算控制器，补偿父级差异，再拟合手臂扭转。无需 OZO Tools 面板或 ARP；不要注册归档插件的 UI。

## 约定与适用范围

- 已确认默认保留源根位移与根旋转，包括 `ROOT`、`ROOT_Sec`。后续同类动画沿用；用户另有指示时再改变方案。内置转换器只实现保留，不把其他根运动方案冒充现成功能。
- 当前只校准 **Man → Girl、FK 双臂＋IK 双腿**。不能反向套用，也不能直接用于改过静止骨架、IK 手臂或其他角色。检查失败先说明具体条件，不能改骨名、覆盖校准文件或放宽阈值来绕过。
- 本 Skill 的“转换/修复”请求允许自动生成、验证并提交新 Action，不套用 ARP 工作流里用户手动点击正式重定向的约定。“检查”只读；不因此执行转换。
- 保留源与原目标 Action、用户最新调整、骨轴、层级、约束和网格。新 Action 是独立数据块，不是在原 Action 中加 Slot；仍需绑定正确的兼容 Slot。
- 本 Skill 不自动保存 `.blend`。只有本次或此前明确要求保存时才保存。原对话中的场景路径、Action 名及帧数是案例，不能作为新任务的输入默认值。

## 连接与检查

发现 Blender MCP 工具。多个窗口/实例时列出文件与实例标识，让用户选定；不要默认连接前台、最新文件或固定端口。连接后用 `bpy.data.filepath`、场景对象核对身份。MCP 不可用时说明阻碍，不把旧磁盘场景当实时结果。

读取当前源/目标骨架、活动 Action 和实际 Slot、完整关键帧范围、对象变换、NLA、模式和当前帧/子帧。常见对象名为 `Man_Armature`、`RIG_Girl`，以用户选定对象为准；源可为 Link/Override，目标必须本地可写。

先读 [执行接口与约束](references/execution.md)，加载 `scripts/run_transfer.py` 并调用 `check()`。它核对完整静止配置、164 项显式映射和支持的通道。范围取当前真实源 Action，不能用时间轴播放范围替代。`check()` 不等于完成逐帧模式、姿态或网格验收。

报告映射数量、源 Action/Slot、帧范围、Bake Step、根运动方案及阻碍。已知对应含 `Torso → Troso`、手指/掌骨追加 `_FK`、异常手臂 Tweak 名纠正；完整表在 `assets/bone_mapping.json`。`assets/man_girl_profile.json` 保存两套骨架的静止矩阵、长度、层级和继承设置。

## 转换与修复

读 [执行接口与约束](references/execution.md) 后使用 `run()`：

1. 重新核对实时基线。通常 `step=1.0`，表示每帧烘焙；需要更密采样时用 `0.5` 等。支持 `0 < step <= 1`，自定义范围必须明确；默认完整源范围。
2. 先完整缓存源姿态，在隔离骨架和新 Action 内转换。保留根曲线与合法属性曲线；写入控制器分组。内置转换包含父级补偿及 12 个手臂 Tweak 的有限次扭转拟合，保持四元数符号连续。
3. 自动验收包含不大于 0.25 帧的中间采样。失败不替换目标 Action，不连续重试正式结果。若仅插值误差失败，可在副本用更小步长重测；若求值结果或参考不适配，先诊断原因。
4. 用户只要求试算时用 `commit=False`，结果 Action 留作候选；用户已要求转换/修复时可用 `commit=True`，候选通过后绑定到原目标，并再对正式目标完整验证。原 Action 保留，失败恢复原绑定和姿态状态。
5. 骨架验收后按动作检查实际网格、肘腕形变、手指、拍手/持物/接地及循环。需要网格检查后才提交时，先用 `commit=False`，通过检查后在最新基线重新执行 `commit=True`，不要直接绑定旧候选跳过验证。

前臂扭转问题或检查指标疑似冲突时，读 [校准方法与已验证边界](references/calibration-and-validation.md)。不要把不同静止 A-pose 的结果骨直接作同一 armature-space 增量比较，也不要靠曲线反号、修改 Bone Roll 或减小步长掩盖系统偏差。

## 验证与交付

自动骨架验收检查：控制器转换、求值结果骨、相对 FK 的手臂扭转、根矩阵、位置/缩放、属性、膝平面与异常拉伸；源与原目标曲线摘要保持一致。腿部与分段扭转等依赖体型的指标单独报告，不能声称所有结果骨完全一致。阈值是这对骨架的工程设置，见参考文件。

动画和接触都以求值结果为准。`scripts/mesh_contacts.py` 可辅助掌面距离/相交检查；不是通用碰撞或接地验收器。检查源是否已有穿插。没有指定地面时，最低 Z 只能诊断。网格检查不自动包含在 `run()` 的 `passed` 中。

交付说明源 Action、原目标/新 Action 名、Slot、范围与步长、采样与误差、根运动、实际网格检查范围、残余问题及磁盘保存状态。让用户能直接播放新 Action。切换旧动作时，未被旧 Action 驱动的 IK/FK 等属性可能残留；必要时恢复记录的模式，不能以已切 Action 代替状态检查。

此预设从实际动画转换与修复工作中整理，随包提供执行脚本和校准数据。原始角色场景、聊天记录及本地诊断归档不属于运行依赖，不随 Skill 加载。
